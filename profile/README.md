## What is Folder Marker?

Folder Marker is a Windows folder customization utility designed to change the appearance of directories in File Explorer. It can apply different colors, symbols, and custom icons to selected folders. Visual differences make important locations easier to recognize without reading every directory name.

Folder colors can represent categories such as active work, completed projects, archived material, or temporary storage. Users may also assign status and priority symbols to indicate how a folder should be handled. The meaning of each marker remains entirely configurable for the selected organization method.

Windows Explorer integration places supported Folder Marker actions in the folder context menu. A directory can therefore be customized directly through a right-click operation. This reduces the need to open the primary interface for every icon change.

Custom folder icons can be loaded from compatible files and organized into reusable groups. Users may maintain separate visual collections for office documents, media libraries, client projects, or personal archives. Original folder appearance can be restored when a custom marker is no longer required.

Folder Marker changes the visual representation of a directory without modifying the files stored inside it. The folder name, content, and location remain unchanged. Icon display can still depend on Windows Explorer settings and the current icon cache.

Folder Marker Custom Icons is suitable for office users, designers, administrators, students, and anyone managing many Windows directories. Its visual organization system complements standard names and directory structures. Consistent colors and symbols can make frequently used storage locations faster to identify.

## Key Features

| Feature | Description |
|---------|-------------|
| Folder Color Assignment | Applies recognizable colors to directories for faster visual classification. |
| Custom Icon Selection | Replaces standard folder graphics with compatible user-selected icon files. |
| Priority Status Markers | Adds visual symbols for important, active, completed, private, or pending directories. |
| Explorer Context Integration | Provides folder customization commands through the Windows right-click menu. |
| Reusable Icon Categories | Organizes custom folder graphics into accessible groups for repeated use. |
| Multiple Folder Processing | Applies selected markers to several directories during one configuration operation. |
| Default Appearance Restore | Removes assigned customization and returns a folder to its standard Windows icon. |
| Non-Destructive Organization | Changes directory appearance without renaming, moving, or altering stored files. |

## Installation Guide

1. Open the Windows installer provided through the repository.
2. Select the preferred application directory.
3. Enable File Explorer context menu integration if required.
4. Complete the installation process.
5. Launch Folder Marker Custom Icons.
6. Select one or more folders to customize.
7. Choose a color, status marker, or compatible custom icon.
8. Apply the change and refresh File Explorer if the new appearance is not immediately visible.
